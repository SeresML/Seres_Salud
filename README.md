# 🏥 Seres Salud - Sitio Web Oficial (Next.js + Tailwind CSS)

Sitio web moderno, responsivo y de alto rendimiento para **Seres Salud (Medicina Laboral y Ocupacional)**. Construido con **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS** y **Lucide React Icons**, optimizado para SEO, accesibilidad y despliegue directo en **Vercel** desde **GitHub**.

---

## 🎨 Características & Diseño

- **Identidad Visual Oficial**: Paleta institucional basada en Verde Esmeralda (`#006E32`), Slate Oxford y acentos en verde vitalidad.
- **Secciones Integradas**:
  - **TopBar & Navbar**: Contacto directo, urgencias ART 24/7 y menú hamburguesa responsive.
  - **Hero Banner**: Titular institucional, métricas clave (+25 años, +500 empresas) y botón de **Turnos Inmediatos**.
  - **Catálogo de Servicios**: Exámenes preocupaciónales, medicina en planta, unidades móviles, higiene y seguridad, control de ausentismo y atención ART.
  - **Propuesta de Valor**: Seccion institucional detallando la excelencia médica.
  - **Formulario Interactivo de Turnos**: Selección de servicios y mensaje directo.
  - **WhatsApp Flotante**: Botón directo de chat interactivo.
- **Preparado para SEO**: Metadata nativa con Open Graph y soporte para redes sociales.

## 🚀 Inicio Rápido (Desarrollo Local)

### 1. Clonar el repositorio e instalar dependencias

```bash
git clone <URL_DE_TU_REPOSITORIO>
cd seres-salud-web
npm install
```

### 2. Iniciar servidor de desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

## 📤 Pasos para Subir a GitHub

### 1. Inicializar Git y realizar el primer commit

```bash
git init
git add .
git commit -m "feat: Lanzamiento inicial web Seres Salud en Next.js"
```

### 2. Vincular con GitHub y subir cambios

1. Crea un nuevo repositorio en tu cuenta de GitHub (ejemplo: `seres-salud-web`).
2. Copia y ejecuta los siguientes comandos en tu terminal:

```bash
git branch -M main
git remote add origin https://github.com/TU_USUARIO/seres-salud-web.git
git push -u origin main
```

## ⚡ Despliegue en Vercel

1. Ingresa a [Vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **"Add New"** -> **"Project"**.
3. Selecciona tu repositorio `seres-salud-web`.
4. Vercel detectará automáticamente que es un proyecto de **Next.js**.
5. Haz clic en **"Deploy"**.

¡En menos de 2 minutos tu sitio estará en producción con certificado SSL gratis y CDN global!
